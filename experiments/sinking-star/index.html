Les Îles du Reflet

SS01 — Marchand. Trois niveaux pilotes, avant les huit niveaux du jeu complet. Cellules logiques de 3 × 3 pixels, affichées sans lissage.

Marchand orange ; pixel blanc = direction.Destination jaune : rejoindre cette case.Miroir : deux rayons cyan, même distance de chaque côté.Eau : pas de déplacement ni d’arrivée dessus.

Flèches : marcher. Espace : passer sur l’autre rayon, à distance égale du miroir. Rouge : essai de pouvoir impossible. Le Marchand n’a pas besoin de regarder le miroir lorsqu’un seul miroir est utilisable.

Aucun SRA, solveur, serveur, Python ou accès réseau dans cette démonstration. Les autres personnages ne sont pas encore jouables.

Prototype original inspiré de mécaniques de réflexion. Cartes originales, aucun asset du jeu source. Hors catalogue et hors site publié.
