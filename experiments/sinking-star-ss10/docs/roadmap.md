# Série Sinking Star — jalon SS10

SS10 **L’Entrepôt Réversible**, version **0.1.0 / HTML v1**, réunit le Guerrier rouge et le Voleur vert. Le contenu conçu atteint **10 jeux sur 25 et 80 niveaux sur 200, soit 40 % en nombre**. Ce pourcentage compte les laboratoires conçus et ne mesure ni l’effort restant, ni la publication du Site, ni la réussite autonome du SRA.

## Livraison

Huit salles avec un tutoriel de douze découvertes. Les autres cartes adaptent des énigmes des guides Nord / Zones mixtes : Hauling 16, Water 3, Mirrors 4 et 5, Water 6, Light 2, puis une synthèse Water 3–4 / Mirrors 6.

Le laboratoire est sauvegardé dans `experiments/sinking-star-ss10/` sur la branche `feat/ss10-duo-lab-20261119`. Le compte rendu donne le commit effectivement poussé. Cette étape livre la version HTML à essayer ; l’intégration du catalogue de production et la publication Site suivent la validation de cette version.

## Suite

1. Essayer l’HTML SS10 et ajuster les cartes selon le retour utilisateur.
2. Intégrer la version retenue sur `main`, puis fournir le prompt de raccordement natif.
3. Valider la parité du runtime, les commandes, les animations, le tutoriel et la non-régression ; publier le Site depuis le code durable sur GitHub et vérifier les deux identités.
4. Poursuivre avec **SS11 — La Force Transposée**, duo **Guerrier + Magicien**.
