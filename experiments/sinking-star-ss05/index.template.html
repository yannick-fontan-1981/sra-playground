Un pas, tout un cortège

Chaque flèche déplace le Barde d’une case. Les caisses, monstres et appuis situés à deux cases autour de lui tentent le même déplacement : c’est un carré de 5 × 5 cases, diagonales comprises. Le chant traverse les murs. Les pointillés magenta délimitent sa portée.

Un objet bloqué reste sur place ; les autres peuvent avancer. Si le Barde ne peut pas faire son pas, tout le déplacement est annulé. Le point blanc indique sa dernière direction.

Flèches : marcher et entraîner les objets proches.
Espace ou X : activer les miroirs · Z : annuler · R : recommencer.

Niveau 1 · L’atelier du chant

  • Avancer avec le Barde magenta.
  • Entraîner une caisse avec le chant.
  • Laisser un objet bloqué pour se replacer.
  • Créer ou déplacer un appui sur l’eau.
  • Changer d’axe avec un miroir.
  • Ouvrir un passage avec un bouton.

Le chant accompagne chaque pas ; il n’a pas besoin d’une touche séparée. Quand tu t’éloignes de plus de deux cases d’un objet, tu le laisses sur place. Un mur peut le retenir sans arrêter ton chant.

Une caisse dans l’eau devient un appui marron avec un X cyan. Le chant peut le faire glisser sur l’eau, mais ne peut pas le remonter sur le sol. L’appui sur lequel tu te trouves ou vas poser le pied reste en place pendant ton pas.

Les reflets · Espace

Espace active les miroirs fixes ; X reste disponible. Sur chaque face blanche, le premier occupant de chaque axe est envoyé à distance égale sur l’autre axe. Le Barde, les caisses et les monstres peuvent être reflétés ; les appuis immergés restent en place.

Un + gris clair prévisualise l’arrivée du Barde ; un contour carré gris clair indique celle d’une caisse. Un mur, une porte fermée ou une arrivée occupée peut bloquer toute l’opération. Un reflet ne déclenche pas le chant.

Un reflet peut jeter une caisse dans l’eau et créer un appui. Le Barde a besoin de sol ou d’un appui à l’arrivée ; un monstre qui tombe dans l’eau disparaît.

La porte qui pousse

Lorsqu’une porte apparaît, elle pousse l’occupant de sa case dans le sens du chevron. Une file de caisses avance ensemble.

Le petit repère coloré relie chaque bouton à ses portes. Si plusieurs boutons portent le même repère, ils doivent être occupés ensemble. Selon la porte, leur activation l’ouvre ou la ferme.

Une caisse poussée dans l’eau forme un appui. Le Barde peut se noyer ou être écrasé si le passage est bloqué. Z permet de revenir avant toute la séquence.

Guider les monstres

Les monstres noirs marqués d’un X rouge suivent le chant quand ils sont à portée. Ils peuvent peser sur un bouton, être reflétés et être déplacés par une presse.

Évite de terminer une action juste au-dessus, au-dessous, à gauche ou à droite d’un monstre. Un contact diagonal ne déclenche pas d’attaque.

Deux monstres côte à côte s’éliminent mutuellement. Ils attaquent encore dans cette même action : garde une case de distance, même si leur rencontre va les faire disparaître.

Huit énigmes autour du Barde : un atelier guidé, des reprises et adaptations d’Order of the Sinking Star, puis des combinaisons de miroirs, eau, monstres et presses latérales. La référence et le type de reprise sont indiqués pour chaque salle.
