La même flèche, deux capacités

Le Guerrier

Il pousse toute une file de caisses, miroirs, monstres ou Barde. Chaque occupant avance d’une case si l’extrémité de la file peut passer.

Le Barde

Chaque pas entraîne le Guerrier, les caisses, les monstres et les appuis dans son aura. Les pièces bloquées restent en place. Les miroirs ne suivent pas.

Les deux peuvent activer les miroirs avec Espace. Changer de personnage ne consomme pas de tour. Pousser le Barde avec le Guerrier permet de le replacer sans faire chanter son cortège.

Construire puis déplacer le passage

Une caisse plongée dans l’eau devient un appui marron marqué d’un X cyan. Le chant peut le faire glisser sur l’eau, mais pas le remonter sur le sol. Un appui occupé par un héros, ou celui sur lequel le Barde va poser le pied, reste ancré pendant ce pas.

Le premier héros arrivé ne disparaît pas. Les deux contours jaunes doivent être occupés simultanément pour terminer la salle.

Le Barde · la portée et les obstacles

Dans la série SS, le chant agit dans une aura carrée. Cette adaptation est commune aux jeux du Barde ; les énigmes sources sont réagencées autour de cette règle.

Un carré de 5 × 5 cases. Le chant prend les occupants à deux cases au plus du Barde, diagonales comprises, avant son pas. Le périmètre en pointillés magenta indique cette portée quand il est sélectionné. Les murs ne coupent pas le chant.

Tous tentent le même pas. Le Guerrier, les caisses, les monstres et les appuis essaient de suivre le Barde dans sa direction. Un membre bloqué reste sur place ; il peut en retenir d’autres derrière lui. Le Guerrier entraîné ne pousse pas une pièce supplémentaire.

Le Barde doit pouvoir avancer. S’il est bloqué, tout le déplacement est annulé. Il n’existe pas de chant sur place. Un objet hors de la portée ne suit pas : éloigne-toi pour changer le groupe entraîné.

Les miroirs ne suivent jamais le chant. Le Guerrier peut les pousser. Espace / X active leurs reflets, sans déclencher le chant. Une presse ou le Guerrier peut aussi déplacer le Barde sans entraîner le groupe.

Un appui glisse uniquement d’une case d’eau vers une autre. L’appui sous un héros et celui où le Barde va marcher restent ancrés. Tu peux ainsi faire avancer un passage, puis traverser sans le perdre sous les pieds.

Lire et déplacer un miroir

La diagonale blanche est sa face réfléchissante ; le dos est noir. Regarde le premier occupant sur chacun de ses deux axes : seul le plus proche du miroir traverse, à distance égale sur l’autre axe. L’autre reste en place. À la même distance, les deux échangent leurs places.

Une arrivée bloquée pour l’occupant plus éloigné n’empêche pas le plus proche de passer. Vérifie le trajet et l’arrivée de celui qui part.

Le + gris clair prévisualise l’arrivée d’un personnage ; le contour carré gris clair celle d’une caisse. Espace ou X active tous les miroirs ensemble, quel que soit le héros sélectionné.

Le Guerrier peut pousser un miroir. Son orientation reste fixe ; le déplacer change ses axes et ses arrivées. Le Barde peut y amener plusieurs objets, puis se faire pousser hors de l’axe avant d’activer le reflet.

Les personnages, caisses et monstres peuvent être reflétés. Les appuis immergés ne le sont pas. Un mur, une porte fermée ou un autre miroir bloque le trajet. Le socle noir d’un miroir qui empêche un autre reflet clignote en rouge quand tu appuies sur Espace. La diagonale blanche reste lisible. Deux miroirs qui donnent des destinations incompatibles signalent leurs socles ensemble. Les reflets ne déclenchent pas le chant.

La porte qui pousse

Un + rose réagit au poids d’un personnage, d’une caisse, d’un monstre ou d’un miroir. Le petit repère coloré relie le bouton à ses portes. Avec plusieurs boutons de même repère, ils doivent être occupés ensemble.

Quand la porte se ferme, elle pousse l’occupant de sa case dans le sens de son repère. Une file entière avance, même si c’est le Guerrier qui a déclenché la porte.

Selon le circuit, appuyer ouvre la porte ou la ferme. Un objet peut maintenir le bouton pendant que tu explores l’autre côté. Ton partenaire peut aussi servir de poids.

La presse peut envoyer une caisse dans l’eau, pousser un héros, déclencher une autre porte ou écraser son occupant si la file est bloquée. Observe toute l’animation avant d’agir ; Z revient avant la cascade entière.

Les portes-plateformes dans l’eau

Une plateforme déployée porte les personnages et les objets. Lorsqu’elle se retire, elle laisse de nouveau de l’eau. Le repère coloré indique le bouton qui la commande.

Un circuit peut déployer une série de plateformes et retirer l’autre. Quitte la série qui va disparaître avant de faire basculer son bouton. Vérifie aussi la case de ton partenaire.

Espace active tous les miroirs. Une caisse reflétée peut changer un bouton et faire apparaître ou disparaître les plateformes pendant cette même action. Les appuis bruns avec un X cyan restent en place pendant un reflet ; le chant peut les déplacer sur l’eau.

Monstres · distance et rencontre

Les monstres noirs marqués d’un X rouge peuvent être poussés, entraînés par le chant, reflétés et déplacés par une presse. Ils peuvent aussi maintenir un bouton. Les guider à distance permet de préparer une rencontre sans exposer les héros.

Après chaque action réussie, ils frappent les voisins au-dessus, au-dessous, à gauche et à droite. Une diagonale n’est pas un contact. Vérifie la sécurité de chaque personnage. Pense aussi au héros que tu ne contrôles pas.

Deux monstres côte à côte s’éliminent mutuellement. Ils frappent encore pendant cette même action : garde une case de distance avec les héros, même si les monstres vont disparaître.

Le coup montre la préparation, l’avancée, l’impact, la désagrégation et le résultat. Annuler reste disponible pendant cette animation.
