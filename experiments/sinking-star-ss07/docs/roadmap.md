# Série Sinking Star — état après SS07

## Livraison actuelle

**SS07 — La Distance Dérobée**, version **0.1.1 / HTML v2**, apporte huit salles avec un Marchand orange, un Voleur vert et deux destinations. Le premier niveau concentre neuf apprentissages ; les suivants développent le déplacement des miroirs, les appuis, les boutons, les presses, les monstres et les plateformes hydrauliques.

Le laboratoire est préparé sur `feat/ss07-duo-lab-20261119`. L’HTML constitue la version à essayer et à valider avant son passage sur `main` et son intégration dans SRA Playground.
