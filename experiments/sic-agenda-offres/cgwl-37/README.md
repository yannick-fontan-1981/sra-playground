`operateur.mjs` accepte `--variante nominal|sans-corps|sans-correspondance|sans-deplacement|sans-attache|stationnaire`. Pour `sans-correspondance`, passer `--cible empty_frame:3060f8c6379a23c26b77f236`. Le filtre n'intervient qu'au T2 entre la mesure et le DRM. Le pré-événement et le reçu d'exécution sont distincts.
