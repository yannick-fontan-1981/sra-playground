Flèches : marcher et pousser dans la direction choisie.
Une file de pierres avance d’une case par poussée.

Niveau 1 · Tutoriel guidé

  • Se déplacer avec les quatre flèches.
  • Pousser deux pierres alignées avec une flèche.
  • Créer un pont : la pierre immergée devient immobile.
  • Maintenir les deux + roses pour ouvrir la porte.

Rejoins ensuite le contour jaune. Une pierre coincée ? Z annule, R recommence. Si la file est bloquée, la flèche ne la déplace pas.

Niveau 1 original. Niveaux 2–8 adaptés de transcriptions publiques de Heroes of Hauling (Joric / Order of the Sinking Star). Les changements de rôle sont indiqués. Cette démonstration autonome ne publie pas de mise à jour sur le site SRA Playground.
