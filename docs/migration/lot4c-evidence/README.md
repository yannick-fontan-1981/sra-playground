## Obligations de clôture

La preuve intégrée doit lier le gel natif, les tests déclarés, les cinq contrôles de livraison, les rejeux publics conservés, les appels Facet comparés à une instance Python froide, les restaurations réellement observées et les ablations négatives aussi bien que positives. Le résultat brut du jeu et son horloge cumulée de 2 400 secondes doivent rester distincts de la parité de composant.

La mesure officielle vient après ces contrôles. La préparation ne lance aucune mesure. Le lanceur d'isolation doit vérifier les signaux de coordination et tenir le verrou commun pendant les quatre séries. Les durées et signatures défavorables restent dans les preuves. Le verdict global par jeu, les diagnostics de phases et une éventuelle qualification structurelle sont des résultats séparés.

La publication finale doit conserver l'accès du Site existant et identifier le commit, le gel, le build et le déploiement effectivement réussi.
