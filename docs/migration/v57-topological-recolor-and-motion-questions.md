## Recovered V5/V6 recolor behavior

The original `topological_recolor` entry is connected at position 18 of the material declaration list. Among currently implemented providers it follows `observed_framed_transfer` and precedes `reactive_contact`. One `public_topological_recolor` owner serves the entry. No duplicate state or activation owner is installed for it.

The three local V6 modules are transferred on the admitted public raster and finite JSON domain:

| Original V6 module | Native implementation | Responsibility |
|---|---|---|
| `topological_recolor/geometry.py` | `v6-topological-recolor-geometry.ts` | Current wells, partition, legend, visible pockets and correspondence |
| `topological_recolor/policy.py` | `v6-topological-recolor-policy.ts` | Original local DRM conditions and priority through SRC |
| `topological_recolor/family.py` | `v6-topological-recolor.ts` | Proposals, exact point guards, return comparison and retained state |

The original `recolor.drm` and `v6.topological_recolor.choose` workflow execute through the shared native registry. The workflow was already compiled, so the inventory remains **37 programs**. Source-facing receipts preserve `workflow`, `src_hash`, `src_status` and `executed_statements`; extra native execution metadata does not enter source identities.

The V5 dependency transfer is deliberately bounded. It includes the consumed `RecolorRegion` fields, digital component flood, enclosed-pocket measurement, neighbour enumeration, work budget and interruption fields. It does not claim the entire 771-line V5 recolor planner, the full digital topology module, general request validation or the whole mechanical family framework. These dependencies remain partial mappings. The exact consumed V6 bounds remain **50,000 visited nodes, 1,000 milliseconds and 20,000 complement-domain cells**. An interrupted computation is not turned into a completed topology receipt.

The six source fields remain explicit:

```text
epoch, selection, writes, attempts, portable, last
```

They are retained in a versioned `native.public_topological_recolor.v1` checkpoint. Current source support must still match before a carried selection method can be used. An epoch change clears current selection/write/attempt state and keeps only revisable method hypotheses in `portable`. A previous method is not a current execution permit.

Acquisition preserves an important source distinction: **only a selected recolor proposal calls its record method**. A foreign public action does not become a recolor experiment. The common caller retains nonempty selection/write/attempt state before FramedTransfer's acquisition, at its original relative position. Each selected actual return creates one `topological_recolor_event`; the authoritative native checkpoint is then restored before further planning.

Point choice uses currently measured supports. If a region's bounding-box centre is a hole, the source fallback chooses a point on that region. Closed pockets in a clipped field retain their partial-topology qualification. A visible paint effect remains `goal_confirmed: false`; only the game host can supply official completion.

## Recovered current motion questions

`v6-motion-contrast.ts` transfers the original `motion_offers` producer and its consumed geometric helpers. It reuses the already ported component observer, snapshot representation, registration, motion models and composition identity. The reused result of `geometry.pairs(...)[1]` is explicitly the component projection; no claim is made for the complete pair detector or `measure_routes`.

The producer compares two conditional explanations of a witnessed control: a fixed measured displacement and continued movement until a matching observed obstacle. It requires public movement and stationary-command witnesses, independently traversed surface evidence, a currently bound rigid participant and a current distinguishing gap. Image edges do not become assumed walls. Protected cells, available actions and remaining resources constrain the experiment. A return route is reported only when directed transitions for that return were actually observed.

The common information caller now performs the consumed source sequence:

1. Read the already acquired meter forecast.
2. Collect point-contrast offers and coupled-display offers.
3. Compute motion offers from the same acquired Goal episode and current public snapshot.
4. Elect the information question with the source resource and preservation rules.
5. Reconcile the chosen hypothesis with the actual public return after prefix sealing.

This adds no persistent motion owner. It also adds no planning-time meter observation: that earlier observation belongs to the still-pending `MorphologyAdapter` provider. The existing collection-before-meter acquisition order is preserved. On a level boundary the acquired meter and Goal episode change scope rather than carrying current movement authority into the next level.

The full strategy's unbound-parent and control-acquisition admissions depend on `morph.last` and its measured `pair_ref`. They remain outside this transfer. `morphology`, `attention_parent_return` and `acquire_control_for_target` remain explicitly pending. This release does not relabel them as completed providers.

The evidence logger observes actual production-instance methods without changing arguments, results, ordering or state. Motion snapshots are stored once by public reference, with consistency checks; histories contain references instead of repeated rasters. This avoids retaining quadratic copies of the same images while keeping complete public provenance. The logger does not execute in the product browser worker.
