## Recovered V5 and V6 logic

The family measures an oriented square field and a unique outline from the
current public raster. Once an actual directional input has translated that
outline on the same measured lattice, it can propose a local process question.
Later ordered public animation frames can provide evidence for a conditional
intervention on an earlier incoming chain while preserving a later suffix.

The transfer preserves the source's uncertainty. An observed order of marker
changes does not establish complete phase rules, quotas, terminal roles or
overlay blocking. A shortest geometric witness remains conditional on the
subsequent real input and its current guard.

### Original policy and projections

The original local priority is preserved:

1. `cover`: test the first measured shortest-route edge toward the earlier
   incoming chain.
2. `protected`: test the process after current measured cover is achieved.
3. `continue`: continue a currently observed process under retained cover after
   progress without restoration.
4. `probe`: test local nontranslation evolution after observed control
   translation.

The three projection rows are copied verbatim from declaration 217,
`policy.declared_initial_interaction_exploration`, in the pinned V5
`interaction.drm`:

| Zero-based projection index | Exact projection ID |
| ---: | --- |
| 519 | `projection.exploration.ordered_tip_process_probe` |
| 520 | `projection.exploration.ordered_tip_intervention` |
| 521 | `projection.exploration.ordered_tip_achieved_cover_activates_process_test` |

Each offer must satisfy its original local conditions and the projection's
conditions. Ties retain the original request order. Missing template inputs
cause abstention. The original `ACTION1`–`ACTION4` directional priors and
`ACTION5` process prior remain explicitly revisable interface hypotheses.
They provide no observed control record by themselves and do not label a
particular game's controls as known.

`v6.ordered_reaction.choose` executes through the common native program
registry. Its source-facing receipt contains exactly `workflow`, `src_hash`,
`src_status` and `executed_statements`. Additional native execution metadata
stays in the native handle, so the original nested offer and state identities
remain literal. No new workflow is appended to the 37-program bundle.

## Ordered public animation evidence

The measurement receives the public frames returned by one actual command in
their original order. It infers square size, marker value, stride and lattice
phases from repeated morphology. It assigns cell-type IDs in row-major
first-occurrence order, compares changed rows first and only reclassifies
affected cells. Sparse deltas retain every frame ordinal, including a frame
with no cell change.

For each original marked square, the packet records its first marker loss,
first marker-preserving recolor and whether the final cell matches the initial
cell. At least two squares must lose markers for a distributed packet to be
retained. A temporal incidence requires the original strict order: an earlier
incoming marker loss, a junction recolor, then an orthogonal later incoming
marker loss. The suffix witness must end at an intact terminal with a distinct
initial value. The source neither invents missing frames nor converts equal
initial and final rasters into an assertion that nothing happened.

Scope, mode ambiguity and route measurement keep the original restrictions:

- At most 256 inferred lattice cells and at most 256 ordered frames are
  admitted by the consumed source measurement.
- Ring association uses the current field plus compatible retained field
  geometry, with the original one-cell margin.
- The uniform patch mode must be unique; it is a measured value, not an
  assigned floor colour or guaranteed traversability rule.
- The route calculation performs one bounded breadth-first search, preserving
  the declared direction order. It returns at most one shortest witness.
- The owner retains at most 16 control receipts and four distinct ordered
  packets. Duplicate observations do not evict unrelated packets.

Coordinates remain row/column throughout this source closure. Palette
permutations, translated fields, rotated scenes and renamed action inputs are
separately compared with original Python. No game identifier, fixed colour
role or prepared solution sequence enters these measurements.

## One state owner and current guards

The exact source fields remain:

`epoch`, `control`, `packets`, `attempts`, `progress`, `history`.

The material selector reaches the single `ordered_reaction` declaration
immediately after the existing `reactive_contact` entry. The owner does not
introduce an earlier native priority. A proposal requires a current measured
field, unique outline and a control receipt with the same stride, size and
row/column phases. It binds the exact current observation reference, epoch,
frame hash and completed-level count.

Before execution, the family remeasures the real current raster and must find
exactly one offer matching the retained source offer. Altered actions,
predictions, scope or unavailable inputs cannot retain the original permit.
After execution, a cover input compares the observed outline position with
the declared next position. Process effects remain unknown when the source
has no narrower prediction. Ordinary WHY/ACT and OP29/OP30/OP31 still govern
physical release and sealed-prefix reconciliation.

An official level boundary clears current control, packets, attempts and
progress. Existing packets may enter history with
`authority: history_only_no_current_permit`. Historical observations cannot
supply current control or authorize an input on the next level. History is
retained according to the source; this release does not invent an additional
history-truncation policy.

### Acquisition position and memory

The original passive acquisition order is OutlineService, ObservedInventory,
OrderedReaction, then ReactiveContact. ObservedInventory remains a documented
pending owner. Among the connected owners, v55 acquires OrderedReaction after
OutlineService and before ReactiveContact; this does not establish completion
of the intervening original dependency.

Each actual returned primitive is acquired once after its prefix is sealed.
Selected OrderedReaction returns use the selected route. Returns selected by
another family are supplied passively with no selected reaction proposal,
preserving the complete public animation packet. Resume does not replay an
already acquired physical event.

Source events are retained as `reaction_event:<revision>`. The source
`reaction_state` fact is written when control, packets or history is present,
then restored through the source projection. The complete immutable native
checkpoint is separately stored under `family_state:public_ordered_reaction`
with format `native.public_ordered_reaction.v1`. Detached state views and
authoritative restoration prevent a speculative mutable copy from replacing
the actual acquired return.
