## Method and boundary

The scan decoded the first three initial previews of 77 games from the published gallery atlases: **231 frames**. Both atlas hashes and the decoded 64 × 64 palette-index frame hashes matched `content/game-gallery-assets.json`. Another 69 frames used different palettes and were skipped; their exclusion is not a capability result.

Only existing pure scene measurements were called. No proposal, action, live game, authored level file, hidden game state or solution oracle was used. The decoded previews are candidate-selection evidence and must not initialize campaign memory. Detailed public hashes, measured signatures, source paths, prerequisites and proof qualifications are retained in [candidate-selection.json](candidate-selection.json).

Existing source-contract fixtures support the families' individual semantics, but do not establish fresh common-agent success on these games. AS66's prior three-level standalone result included 16 externally imposed public probes; GLOB's prior result covered one level with four probes. MEMO's isolated three-level result did not transfer to the earlier common-agent campaign. None is counted as a new success here.
