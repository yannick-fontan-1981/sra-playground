# Entry and managed morphology: absolute component results

**All twelve fixed positive cases passed their source-output assertions.** The dedicated run executed 36 warmup calls and 240 measured calls. Both source fixtures, their generators, this run's declared protocol and the native source inventory remained unchanged across measurement. Fixed component premises were unchanged; each entry consumer's deliberately enriched working facts matched the original exactly.

This is an absolute warm-component diagnostic. It has no V62 denominator, does not replace the common-loop 10% gate, and does not measure cold Kernel acquisition or game execution. The [declared protocol](managed-component-protocol.md) identifies all injected consumer premises and excluded costs.
