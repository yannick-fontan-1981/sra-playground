# Les niveaux à dépasser avec SIC seul

Chaque ligne cumule les meilleurs scores retrouvés sur des parcours continus partis du niveau 1 avec un score initial de zéro. Les résultats concernent la même entrée du catalogue. Un tiret indique une preuve manquante. Un zéro indique qu’un essai borné a été retrouvé avec zéro niveau gagné.

Le seuil provisoire est le maximum des scores attestés. Le prochain score à atteindre est ce seuil plus un, avec le nombre total de niveaux comme plafond. Lorsqu’une version avait déjà gagné le jeu, le jalon est une victoire complète de SIC seul. Les jeux dont le seuil manque restent à documenter. Un parcours commencé à un niveau intermédiaire est utile pour faire des diagnostics, et ne fixe pas ce seuil.

V5 inclut les parcours continus attestés et les niveaux 1 qualifiés. V6 désigne l’agent source. Pour V7, les cinq rapports locaux examinés indiquent zéro partie démarrée, dont un rejeu de retours historiques. La colonne reste ouverte à d’autres archives V7.
