## Reproduction

Depuis la racine du candidat avec Node 24 et les dépendances du dépôt installées, la première commande teste les paquets conservés. Définir `SIC_SP80_GAME_ROOT` sur un checkout contenant `public/python` et `public/vendor/pyodide` fait rejouer les décisions nominales et les quatre substitutions dans le jeu public. Avec `SIC_SP80_ENGINE_ROOT` pointant sur un checkout du gel, les tests importent son moteur. Les quatre substitutions par les interfaces ajoutées sont alors signalées comme inapplicables.

~~~powershell
node --test tests/sic-sp80-two-lines.test.ts
$env:SIC_SP80_GAME_ROOT = (Get-Location).Path
node --test tests/sic-sp80-two-lines.test.ts
node --test --test-concurrency=1 (Get-ChildItem tests/v6-branch-routing*test.ts, tests/v6-cell-placement*test.ts).FullName
npm run typecheck
~~~
