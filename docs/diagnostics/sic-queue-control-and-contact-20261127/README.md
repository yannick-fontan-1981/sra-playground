# Commandes de file acquises et réception maintenue

Le premier défaut public est à la première décision L2 : le noyau peut transférer les quatre effets appris, mais la famille lie leur réemploi au besoin d’un horizon sur toute la file. Le correctif sépare ces deux décisions sans modifier les conditions de compatibilité du noyau. Le premier rejeu gagne quatre niveaux puis s’arrête L5 à 69 commandes.

La capture suivante révèle une réception atteignable perdue à la fin du plan : la famille exécute les préparations, coupe avant la réception connue, puis recalcule et repart. Le complément conserve cette dernière commande déjà prévue. Chaque préparation garde ses contrôles de grille, enveloppe et preview ; la réception ferme le préfixe après son retour réel. Aucun quota ni modèle de fermeture n’est assoupli.

Le second rejeu strict gagne six niveaux en 103 commandes : 17, 17, 20, 23, 10, 16. Sept tests couvrent deux transferts natifs avec formes, palettes, positions et commandes différentes, des rôles/commandes absents, une enveloppe ambiguë et une préparation contradictoire. Le simulateur de retour des tests calcule indépendamment chute, triples et gravité ; la réception finale est exécutée puis réacquise. TypeScript et la revue indépendante passent.

Le manifeste contient les révisions exactes, les budgets, les scores et les empreintes. L’archive déterministe conserve les deux captures publiques, les deux premiers verdicts stricts et le collecteur exécuté. Ce collecteur contient les chemins de l’environnement de diagnostic ; il n’est pas utilisé en production. La qualification du contrôle de continuité, l’intégration, la publication et le viewer restent à réaliser à ce checkpoint.
